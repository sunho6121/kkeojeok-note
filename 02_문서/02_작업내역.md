# 끄적노트 작업 내역

- 작성일: 2026-11-11
- 현재 버전: **kk-v35** (2026-11-28 배포)
- 주소: https://sunho6121.github.io/kkeojeok-note/
- 저장소: GitHub `sunho6121/kkeojeok-note` (공개)
- 이 문서는 PC의 `02_노트정리/02_문서` 폴더에 있고, 배포할 때 앱에도 함께 올라감(설정 → 작업 내역)

## 1. 개요

- 갤럭시탭 S9(S Pen)에서 쓰는 노트 앱(PWA)임
- 1~2개 노트에 계속 이어 쓰고, 신호를 주면 Claude가 일정·할 일·전달사항·중요 메모로 정리함
- 기본 원칙
  - claude.ai와 별개인 독립 앱임
  - 노트 쓰기는 로그인·인터넷 없이 가능함(기기 안 저장소 IndexedDB)
  - Claude는 '정리' 단계에만 씀(사용자 본인 API 키)
  - 기본 모델 Sonnet 5.5, 꼼꼼함(effort) 높음
  - 크레딧이 드는 음성→글자 변환(유료 STT)은 넣지 않음. 녹음 → 글은 기기 안 음성 인식으로 함(무료, 소리는 기기 밖으로 안 나감, kk-v32)
- 화면 원칙: 단순한 목록형, 개조식(~함·~임·명사형) 문체
- 줄 바꿈 원칙: 줄이 바뀔 때 한글 낱말(어절)을 자르지 않음. 화면·PDF·한글(HWPX)·Word 모두(kk-v34)

## 2. 기본 사용 흐름

1. 쓰기 탭의 노트에 생각나는 대로 적음(타자 또는 필기)
2. 아침에 날짜만 한 줄 적음(예: `11/12`) → 전날까지 못 끝낸 일이 아래에 들어오고, 우선순위 창이 뜸
3. 마지막 줄에 `//`(또는 `@정리`, `정리!!`)를 쓰거나 **정리하기**를 누름 → Claude가 정리함
4. 업무·일정·전달·메모 탭에서 상태를 바꾸고 확인함
5. 회의는 녹음 → 녹취 글 공유 → 회의록 자동 생성(HWPX·DOCX·PDF)

## 3. 기능별 내용

### 3-1. 쓰기·정리

- 노트 칩으로 노트를 바꿈. 이번 달 노트만 보임
- 입력 방식: 타자 / 필기(S Pen). 필기는 정리할 때 글자로 옮겨져 노트에 붙음
- 정리 신호: 마지막 줄에 `//`, `@정리`, `정리!!` 또는 **정리하기** 버튼
- 인터넷이 없거나 API 키가 없으면 '정리 대기'로 두고, 연결되면 자동 정리함
- 정리 규칙(Claude)
  - 종류: 약속(event) · 할 일(task) · 전달사항(notice) · 중요 메모(memo)
  - 상태: 예정 · 진행중 · 보류 · 완결 · 취소. 기한이 지난 미완료는 '미완결'로 표시함
  - 같은 일은 기존 항목에 합치고(e1… 번호), 사용자가 직접 바꾼 상태·지운 항목은 건드리지 않음
  - 급함·꼭·중요·!!·★ → 우선순위 높음
  - 전달·메모는 제목 25자 이내 명사형, 설명 1~3줄 개조식
- 붙여넣기 버튼: 다른 앱에서 복사한 글·이미지를 노트에 넣음(이미지는 정리할 때 글자로 옮김)
- 받아쓰기: 브라우저 음성 인식(무료)으로 말을 글자로 적음

### 3-2. 날마다 이어 쓰기 · 우선순위 (kk-v19)

- 노트에 **날짜만 한 줄** 적으면, 그 아래에 전날까지 못 끝낸 일을 불러옴
  - 알아보는 형식: `11/12`, `11.12(목)`, `11월 12일`, `2026.11.12.`, `■ 11/12 ■`
  - 줄을 바꾸면 곧바로, 줄을 안 바꾸면 2~3초 멈춘 뒤 불러옴
  - 어제~사흘 뒤 날짜만 대상임. '11/12 회의'처럼 다른 글이 붙은 줄은 제외함
- 불러오는 대상
  - 기한이 지났는데 안 끝낸 할 일·전달사항
  - 기한 없이 전에 적어 둔 할 일
  - 보류는 뺌. 같은 날짜는 노트가 둘이어도 한 번만 불러옴
- 노트에 들어가는 모양(우선순위 → 기한 오래된 순)

  ```
  11/12(목)
  [이어서 할 일 · 11/11까지 못 끝낸 5건]
  - [높음] 동강홀 대관 신청 · 11/6까지·5일 지남
  - [보통] 운영위 자료 초안 작성 · 11/11까지, 진행 중
  - [낮음] 교육 만족도 설문 정리 · 기한 없음
  ```

- 우선순위 창
  - 우선순위를 아직 안 정한 일이 있으면 자동으로 뜸
  - 일마다 높음 · 보통 · 낮음 선택, 이미 끝낸 일은 '끝냄'
  - 저장하면 노트 목록에 `[높음]` 표시가 붙고 다시 정렬됨. 안 고른 일은 '보통'
  - '나중에'를 누르면 노트 위 안내 줄의 '우선순위 정하기'로 다시 열 수 있음
- 직접 정한 우선순위는 Claude 정리·업무보드가 바꾸지 않음
- 할 일 창(항목을 눌렀을 때)과 업무 탭에도 우선순위 표시·변경 기능 있음
- 필기 모드에서는 날짜를 알아볼 수 없음 → 노트 위 안내 줄의 **'지금 불러오기'** 사용
- 불러오기·정렬은 Claude를 쓰지 않아 크레딧이 들지 않음

### 3-2-1. 일정 · 노트 고치기 (kk-v21)

- 항목 창 → **고치기**: 종류·제목·날짜·시간·장소·대상·내용
- 고치면 노트에도 적음(끌 수 있음)
  - 그 일을 처음 적은 부분에 `~~취소선~~`
  - 바로 아래에 `↳ 고침(날짜): 새 내용`
  - 원래 적은 곳은 Claude가 정리할 때 남긴 원문 구절로 찾음. 없으면 비슷한 구절, 그래도 없으면 노트 끝에 기록
- 노트 입력칸에서 `~~ ~~` 구간이 실제 취소선으로 보임. Claude는 정리할 때 이 구간을 무시함
- 직접 고친 칸은 다시 정리해도 Claude가 바꾸지 않음. 되돌리기 가능
- 노트 탭 카드의 연필: 노트 이름 바꾸기·삭제

### 3-3. 업무 탭

- 할 일: **업무별**(기본) 또는 **기한별**(기한 지남 / 이번 주 / 다음 / 기한 없음 / 보류). 같은 묶음 안에서는 우선순위 높은 것부터
- 업무별 묶기(kk-v27)
  - 하나의 업무에서 나온 할 일·전달을 업무 이름 아래에 모음. 묶음마다 끝낸 수/전체, 가장 급한 기한, 접기
  - 같은 업무가 2개 이상일 때 묶음, 하나뿐이면 '그 밖의 할 일'(업무 이름표)
  - 정리할 때 Claude가 업무 이름을 붙임(지금 쓰는 업무 이름을 함께 보내 같은 이름을 씀)
  - 전에 정리된 할 일은 '업무별로 묶기' 버튼(제목·내용·원문 구절만 보냄, 노트 본문은 안 보냄)
  - 고치기: 할 일 창의 '업무: ○○' → 다른 업무로 옮기기·새 이름·묶음에서 빼기 / 묶음 연필 → 이름 바꾸기·합치기·묶음 풀기 / 되돌리기
  - 직접 정한 업무는 다시 정리해도 Claude가 안 바꿈
- 한 일: 이 달에 끝낸 업무 + 회의록
- 월간 업무 요약(Claude): 한 줄 요약, 분야별 내용, 끝낸 일, 넘어가는 일, 기억할 것
- ‹ › 로 달 이동, 지난달은 '다음 달로 넘긴 일'을 보여 줌
- 업무보드 올리기 버튼, '↻ 보드 HH:MM 맞춤' 링크

### 3-4. 월별 노트

- 노트는 달마다 새로 시작함
- 새 달 첫 실행 때 지난달 노트를 닫고, 안 끝난 일을 새 달 노트로 넘김
- 지난달 업무 요약을 자동으로 만듦
- 노트 탭은 달별로 묶어 보여 줌

### 3-5. 일정 탭

- 보기 선택: 목록 / 주간(월~일 7칸) / 월간(월요일 시작 달력, 칸당 3개, +N)
- 월간 달력에서 날짜를 누르면 아래에 그날 목록이 나옴
- 종류(전체·약속·할 일)·상태(남은 일 등) 거르기

### 3-6. 전달·메모 탭

- 전달사항과 중요 메모를 한 줄 목록으로 보여 줌
- 비어 있으면 '노트에서 뽑아 정리하기'
- '간결하게 다듬기': 전달·메모를 개조식으로 다시 씀(Claude)

### 3-7. 녹음 · 회의록

- 녹음 버튼 → 고르는 창(kk-v23): **끄적노트로 녹음** / **음성 녹음 앱으로 녹음**. PC는 끄적노트 녹음만
  - 설정의 '녹음 버튼을 누르면' 항목은 뺌(누를 때마다 고름)
  - 음성 녹음 앱은 저절로 열 수 없음: 웹앱은 다른 앱을 열거나 녹음을 시작하게 할 수 없음 → 작업 표시줄에서 끌어 화면 분할, 앱 페어 안내
- 음성 녹음 앱으로 녹음 (kk-v22)
  - 녹음은 삼성 음성 녹음 앱이 하고 파일도 그 앱에 저장. 그동안 끄적노트를 계속 씀(화면 분할 권장)
  - 끄적노트: 노트에 시작 시각, 녹음 버튼·위쪽에 경과 시간
  - 끝나면 음성 녹음 앱에서 공유 → 끄적노트 → 녹음을 시작한 노트에 붙고(8시간 안) 표시가 꺼짐
  - 예전 방식(음성 녹음 앱이 열려 녹음이 끝날 때까지 그 화면)은 뺌
- 끄적노트로 녹음: 다른 탭을 봐도 계속, 위쪽 ● 표시로 끝냄. 파일은 녹음 탭에(음성 녹음 앱에는 없음)
  - 끊김 대비(kk-v25): 탭 커버를 닫거나 화면이 꺼지면 Chrome이 마이크를 끊거나 앱을 닫을 수 있음
    - 10초마다, 그리고 화면이 꺼지는 순간 녹음 조각을 기기에 저장
    - 앱이 닫혔으면 다음에 열 때 조각을 이어 붙여 살리고 저장할지 물음
    - 화면이 다시 켜졌을 때 마이크가 끊겨 있으면 그때까지를 저장하고 '이어서 녹음'
    - 화면이 30초 넘게 꺼져 있었으면 소리가 빠졌을 수 있다고 알림, 저장 창에도 표시
    - kk-v26: 갤럭시탭에서 커버를 닫은 동안 녹음은 이어지지만 소리가 안 들어가는 것을 확인 → 안내를 "소리가 녹음되지 않음"으로 고침, 10초 넘게 꺼져 있었으면 알림, 저장 창·녹음 탭에 소리 없는 곳을 녹음 안 위치(2:10~4:05)로 표시, 녹음 탭 '소리 빠짐'
    - 화면이 다시 켜지면 화면 켜 두기를 다시 걺. 끊긴 녹음은 녹음 탭에 '중간에 끊김'
    - 다른 창에서 녹음 중인 조각은 건드리지 않음
  - 갤럭시탭 Chrome의 '데스크톱 버전'도 태블릿으로 알아봄
- 녹음이 끝나면 저장 확인 창. 녹음 중 쓴 메모도 함께 저장
- 녹음 탭: 듣기, 보내기, 회의록 만들기
- 녹음 찾기·보내기 (kk-v24)
  - 찾기: 이름·날짜(11/12, 11월 12일)·노트·회의명·장소·참석자·녹취 글·회의록 내용. 녹취 글에서 찾으면 그 줄을 보여 줌
  - 기간: 전체 · 오늘 · 이번 주 · 이번 달
  - 위쪽 검색(돋보기)에서도 녹음을 찾고, 누르면 녹음 탭의 그 녹음으로 감
  - 보내기 창: 녹음 파일 · 녹취 글(.txt) · 회의록(한글·Word·글) 고르기, 메일 제목·내용 자동, 공유 창(메일·카카오톡·드라이브)
  - 여러 개 골라 보내기(한 번에 10개까지), 합계 20MB 넘으면 메일 한도 안내
  - 기기의 공유 창이 받지 않는 형식(한글·Word 등)은 고를 수 없게 함. 공유 창이 없으면 파일로 받기
  - 회의록 창에도 보내기 버튼
- 녹취 글 자동 연결
  - 삼성 음성 녹음 앱 등에서 녹취 글을 '공유 → 끄적노트'로 보내면 최근 녹음과 자동으로 묶음
  - 녹음이 없으면 '녹취 글' 항목을 새로 만듦
- 회의록 만들기(Claude)
  - 양식: 「회의록(원외 & 원내 협의체)」 2쪽 기준, 결재란·주관 칸 없음
  - 칸: 회의명 / 일시·장소 / 참석자 / 핵심요약 / 내용 / 결정사항 / 향후조치 / 첨부자료
  - 내려받기: 한글(HWPX) · Word(DOCX) · PDF(인쇄 화면에서 'PDF로 저장')
  - 향후조치 → 할 일, 결정사항 → 중요 메모로 자동 등록(설정에서 끌 수 있음)
  - 녹취 글이 들어오면 회의록 자동 생성(설정에서 끌 수 있음)
  - 쓰는 법(kk-v33): 안건마다 현황·배경 → 논의 → 결론 차례, 회의에 없던 사람도 앞뒤가 이어지게 대상·이유를 넣음, 가리키는 말 대신 실제 이름, 결정·조치에도 대상, 안 들린 곳은 '(녹취 불분명)', 다 쓴 뒤 스스로 읽고 고침
- 녹음 → 글, 기기 안에서 바꾸기 (kk-v32)
  - Whisper large-v3-turbo(음성 인식 모델)를 브라우저 GPU(WebGPU)로 기기 안에서 돌림. 무료, 녹음 소리는 기기 밖으로 안 나감
  - 끄적노트 녹음을 저장하면 바로, 녹음 파일만 공유받으면 2분 기다렸다가(변환 글이 오면 그 글) 글로 바꾸고 회의록 자동
  - 처음 한 번 모델 받기(약 540MB, GPU에 따라 약 725MB): 받을지 묻고 기기 브라우저에 보관. 설정에서 미리 받기·지우기
  - 말이 쉬는 곳에서 15~28초씩 나눠 바꿈. 소리 없는 조각은 건너뛰고, 영상 자막식 헛말·되풀이는 지움. 줄마다 녹음 안 시각 [00:00]
  - 조각마다 이어 갈 곳을 저장 → 앱이 닫혀도 다음에 이어서. 멈추기·이어서 바꾸기 버튼
  - 녹음 탭: 글로 바꾸는 중 N/M분·남은 시간, 곧 글로 바꿈, 실패, 멈춤, 노트북에서 바꿀 차례
  - 노트북에 맡기기: 태블릿 녹음을 노트북과 맞추기로 받은 노트북이 바꿔 돌려줌(설정 '녹음이 들어오면'에서 기본으로도)
  - 바꾸는 중이나 바꾼 뒤에 음성 녹음 앱 변환 글이 오면 그 글을 씀(회의록이 이미 있으면 그대로 둠)
  - 끄적노트로 녹음하는 동안은 잠시 쉬고 새로 시작하지도 않음, 화면 켜 두기
  - 끊긴 녹음은 '이어서 녹음' 알림 뒤(15초)에 시작. GPU가 없는 기기는 알림 없이 카드에 '이 기기에서 글로 못 바꿈'

### 3-7-1. 관련 자료 · Claude에게 묻기 (kk-v22)

- 관련 자료: 쓰기 화면 '자료' 버튼으로 노트에 파일을 붙임. 본문에는 안 보임
  - PDF·사진은 파일째, hwpx·docx·pptx·xlsx·글은 붙일 때 글자를 뽑아 둠. .hwp는 못 읽음
  - 태블릿에만 저장, 백업 제외, 노트를 지우면 함께 지움
- Claude에게 묻기: 오른쪽 위 말풍선
  - 범위: 지금 노트 / 이번 달 / 전체, 붙인 자료 읽기 켜고 끄기
  - 노트·일정·회의록·붙인 자료를 Claude가 읽고 개조식으로 답함. 근거(노트·자료 이름)를 밝힘
  - 답은 글자가 오는 대로 보임. 이어 묻기는 자료 부분을 캐시해 요금을 줄임
  - 답마다 토큰·어림 요금, 노트에 붙이기, 복사
  - 설정의 API 키를 씀(콘솔 계정). claude.ai 구독 계정은 외부 앱이 쓸 수 없음

### 3-9. 업무보드 연결

- 대상: 공공보건의료사업팀 업무보드 https://uuh-board.uuh-phc.workers.dev/
- 연결: 보드 위쪽 「끄적노트 연결」에서 받은 개인 연결 키를 끄적노트 설정에 넣음
- 끄적노트 → 보드
  - 업무 탭 '업무보드에 올리기'에서 할 일을 골라 올림(담당·사업·분류 추측)
  - 올린 업무의 상태·기한·제목이 바뀌면 보드에도 맞춤
- 보드 → 끄적노트 (kk-v16)
  - 보드에서 바뀐 상태·기한을 받아 반영(보드 쪽 우선)
  - 담당에 내 이름이 있는 미완료 업무를 가져옴('보드' 표시)
  - 보드에서 지운 업무는 끄적노트에서도 지움
  - 받는 때: 앱 시작, 업무 탭 열 때, 5분마다, ↻ 누를 때
- 상태 대응: 예정↔예정, 진행 중↔진행중, 대기↔보류, 완료↔완결, 취소↔취소, 기한 지난 미완료 → 지연
- 우선순위는 아직 보드에 보내지 않음
- 합쳐 올리기(kk-v29)
  - 같은 업무(업무 이름)·비슷한 일(팀 이름·'관련'·'작성' 같은 흔한 말을 빼고 견줌)은 보드 한 줄. 세부 할 일은 올릴 때 보드 메모에
  - 한 줄의 상태: 다 끝나야 완료(모두 취소면 취소), 기한 지난 일이 있으면 지연, 하나라도 진행이면 진행 중. 기한은 남은 일 중 가장 가까운 것
  - 보드에 이미 있는 같은 업무(끄적노트에서 올린 줄·내 담당)에는 새 줄 없이 더함
  - 올리기 창에서 '따로 올리기'·'새로 올리기'로 고침
  - 보드에서 합친 줄을 완료·취소 → 남은 세부 할 일도 끝냄. 보드에서 이름을 바꾸면 줄 이름만 바뀜
  - 겹쳐 올라간 줄(끄적노트에서 올린 것끼리)은 올리기 창 위에 보여 주고, 확인하면 하나만 남기고 나머지는 보드에서 '취소'

### 3-9-1. 노트북과 맞추기 (kk-v28)

- 저장 위치: 내 구글 드라이브의 앱 전용 공간(appDataFolder). 드라이브 목록에 안 보임. 같은 구글 계정으로 켠 기기끼리 맞춤
- 로그인: 구글 캘린더와 같은 OAuth 클라이언트(프로젝트 "sunho note"), 권한은 drive.appdata만. 구글 클라우드에서 Google Drive API를 켜 둬야 함
- 맞추는 것: 노트·필기·일정·할 일·전달·메모·회의록·월간 요약·가져온 파일, 녹음·붙인 파일(설정에서 끌 수 있음)
- 맞추지 않는 것: 설정(Claude API 키·업무보드 키 포함), 녹음 중 조각, 저장 확인 전 녹음
- 문서 하나 = 드라이브 파일 하나. 이 기기에서 바뀐 문서만 몇 초 뒤 올리고, 바뀐 파일만 받음
- 합치기: 마지막으로 맞춘 판과 견주어 노트 본문은 줄 단위로 합침(같은 곳을 양쪽에서 고치면 둘 다 남김), 필기는 획 단위, 그 밖의 칸은 한쪽만 고쳤으면 그쪽·둘 다 고쳤으면 나중 것
- 지금 쓰는 노트는 손을 멈춘 뒤(1.5초) 합침. 정리하는 동안은 기다림
- 지운 문서는 '지움 표시'로 올려 다른 기기에서도 지움(다른 기기에서 그사이 고친 것은 남김)
- 구글 로그인은 1시간 → 위쪽 구름 버튼 '맞추기'를 누르면 다시 로그인
- 켠 뒤 처음 한 번 끝까지 맞출 때까지는 이 기기 문서를 모두 올릴 대상으로 둠(kk-v30). 처음 켤 때 Drive API가 꺼져 있었어도 나중에 다 올라감
- 달 넘기기: 새 달 노트 이름을 정해 두어(시리즈+달) 두 기기가 따로 넘겨도 같은 노트 하나로 맞춰짐. 늦게 온 지난달 일도 이번 달 노트로 넘김
- 구글 캘린더: 다른 기기가 이미 넣은 일정이면 새로 만들지 않음

### 3-10. 그 밖의 기능

- 삼성 노트 가져오기: PDF·글·이미지를 '공유 → 끄적노트' 또는 파일 선택으로 가져와 정리
- 검색: 모든 노트 내용과 녹음에서 찾기, 결과를 누르면 해당 위치나 그 녹음으로 이동
- 백업 내보내기·가져오기(녹음 파일은 용량 때문에 백업에서 뺌)
- 업무 현황 내보내기(kk-v31): 누를 때만, 할 일·일정·전달·회의 결정사항의 제목·기한·상태 등을 글 파일 하나(내용은 JSON)로. 노트 본문·자세한 내용·대상·필기·녹음·중요 메모·키는 넣지 않음. 완결·취소는 최근 60일
- 오프라인에서도 열림(서비스 워커 캐시)

## 6. 보안 · 개인정보 원칙

- Claude API 키와 업무보드 연결 키는 기기마다 앱 설정에만 둠(노트북과 맞추기로도 보내지 않음). 채팅·다른 대화에 붙여넣지 않음
- 노트북과 맞추기를 켜면 노트가 내 구글 계정 드라이브(앱 전용 공간)에 저장됨. 권한은 그 공간만(drive.appdata)
- 노트를 정리하면 내용이 Anthropic으로 전송됨 → 환자 개인정보는 적지 않음
- 회의록 정리 때도 개인정보를 가리도록 지시함
- 업무보드는 팀 공유 자료임. 쓰기 범위는 사용자 확인 후 진행함
- 업무보드 요청서(`_요청서/`)는 공개 저장소에 올리지 않음
- 업무 현황 내보내기는 정한 칸만 새로 담음. 파일은 기기 안에서 만들고, 보낼 곳은 사용자가 고름
- 커밋 작성자는 GitHub noreply 주소를 씀(병원 이메일 비공개)
- 시험할 때는 가짜 응답을 써서 실제 Claude 요청을 보내지 않음. 시험 화면에서 밖으로 나가는 요청은 막음(kk-v31)
- 녹음 → 글은 기기 안에서 함(kk-v32). 녹음 소리는 외부 음성 인식 서비스로 보내지 않음. 밖으로 나가는 것은 모델 파일 받기(허깅페이스)뿐이고, 받는 판을 고정함. 바꾼 글로 회의록을 만들면 그 글은 Anthropic으로 감

## 7. 기술적 한계

- Claude API는 오디오를 받지 않음 → 녹음 글자 변환은 기기 안 음성 인식(kk-v32) 또는 삼성 음성 녹음 앱(Galaxy AI) 변환 글 공유
- 기기 안 음성 인식은 말한 사람을 구분하지 않고, GPU(WebGPU)가 없는 브라우저에서는 못 함. 처음 한 번 모델(약 540MB)을 받아야 하고, 바꾸는 동안 앱을 켜 둬야 함
- 삼성 음성 녹음 앱은 가져오기·공유 받기 기능이 없음 → 끄적노트 녹음을 그 앱에 넣을 수 없음. 그래서 음성 녹음 앱에 남기려면 그 앱으로 녹음해야 함
- 웹앱은 음성 녹음 앱을 뒤에서 녹음하게 켤 수 없음 → 녹음 시작은 사용자가 그 앱에서 함(끄적노트는 시작 표시·경과 시간)
- Claude 앱(claude.ai) 구독은 API 사용량에 포함되지 않고, 외부 앱이 그 계정으로 Claude를 부를 수 없음 → 질문 기능은 콘솔 API 키 사용
- 끄적노트 안에서 한 녹음은 앱 안에만 저장되고, 앱을 닫으면 녹음이 멈춤
- 탭 커버를 닫거나 화면이 꺼진 동안은 웹앱 녹음에 소리가 들어가지 않음(안드로이드가 화면 뒤 앱의 마이크를 막음, 2026-11-20 갤럭시탭 확인). 마이크를 끊거나 앱을 닫을 수도 있음 → 커버를 닫을 녹음은 음성 녹음 앱으로. 끄적노트 녹음은 끊겨도 그때까지는 남게 하고 소리 없는 곳을 알려 줌
- 웹앱은 .hwp(바이너리)를 만들 수 없음 → .hwpx로 제공
- PDF는 인쇄 화면의 'PDF로 저장'으로 만듦
- 웹앱은 기기 캘린더를 직접 읽을 수 없음 → 그룹웨어는 구글 캘린더 동기화를 거쳐야 보임
- 웹앱의 구글 로그인은 1시간이면 끝나고, 다시 로그인은 버튼을 눌러야 함(팝업) → 노트북과 맞추기는 1시간마다 '맞추기'를 한 번 눌러야 이어짐
- 필기(그림)로 쓴 날짜는 알아볼 수 없음
- 회의 STT를 외부 유료 서비스로 붙이는 것은 병원 정보 문제로 보류함 → 기기 안 음성 인식으로 함(kk-v32)
