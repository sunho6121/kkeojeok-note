# 끄적노트

갤럭시탭 S9에서 쓰는 노트 앱(PWA). 노트에 이어 쓰고 신호를 주면 Claude가 일정·할 일·전달사항·중요 메모로 정리함.

- 앱 주소: https://sunho6121.github.io/kkeojeok-note/
- 사용 안내: [02_문서/01_사용안내.md](02_문서/01_사용안내.md)
- 작업 내역: [02_문서/02_작업내역.md](02_문서/02_작업내역.md)

## 폴더 구성

```
02_노트정리/
├─ 01_앱/       끄적노트 앱 (index.html, *.js, sw.js, 아이콘)
├─ 02_문서/     사용 안내, 작업 내역 (앱의 설정 → 사용 안내·작업 내역에서도 보임)
├─ 03_요청서/   업무보드 연결 요청서 (GitHub에 안 올림)
└─ 04_도구/     배포, 한글 양식 변환, 시험 스크립트(시험/은 안 올림)
```

## 배포

- `python 04_도구/deploy.py` 를 실행하면 배포함
  1. `04_도구/build_site.py` 가 01_앱을 복사하고 02_문서의 md를 `docs/`로 넣음
  2. 그 결과를 **gh-pages 브랜치**에 올림 → GitHub Pages가 앱 주소로 보여 줌
- main 브랜치는 원본(이 폴더), gh-pages 브랜치는 배포본임. 배포본은 직접 고치지 않음
- 앱 파일을 고치면 `01_앱/sw.js`의 `VERSION`을 올림(태블릿이 새 버전을 받음, 앱에 '새 버전' 알림)
- 02_문서에 md를 더 넣으면 파일 이름 순서대로 앱 문서 창의 탭으로 나타남(배포해야 반영)

## PC에서 미리 보기

```
python 04_도구/build_site.py <임시 폴더>
python -m http.server 8765 --directory <임시 폴더>
```

브라우저에서 http://127.0.0.1:8765/ 을 엶. 배포 폴더(_site)는 GitHub에 올리지 않음.
