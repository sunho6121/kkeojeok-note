# 끄적노트 (초안 v0.1)

갤럭시탭 S9에서 쓰는 노트 앱입니다. 생각나는 대로 적다가 **신호를 주면 Claude가 정리**해서 일정·할 일로 만들어 줍니다.

- 로그인 없이 쓰고, 노트는 **태블릿 안에만** 저장됩니다 (인터넷 없어도 쓰기·보기·일정 확인 가능).
- '정리'만 인터넷과 Claude API 키가 필요합니다.
- 설치하면 홈 화면 아이콘으로 열리는 **별도 앱**처럼 동작합니다 (주소창 없음).

## 정리 신호 3가지

| 신호 | 방법 |
|---|---|
| 마지막 줄 신호 | 마지막 줄에 `//` 또는 `@정리` 만 쓰고 잠깐 멈추기 (S Pen 손글씨 입력도 됨) |
| 버튼 | 오른쪽 아래 **정리하기** |
| 키보드 | `Ctrl` + `Enter` (북커버 키보드 사용 시) |

인터넷이 없을 때 신호를 주면 노트에 **정리 대기**가 붙고, 연결되면 자동으로 정리됩니다.

## 쓰는 방법

- **타자 모드**: 줄 노트에 바로 입력. S Pen으로 입력칸에 직접 쓰면 삼성 키보드가 글자로 바꿔 줍니다.
- **필기 모드**: S Pen으로 자유롭게 쓰기 (필압 반영, 펜을 쓰는 동안 손바닥 터치 무시, 지우개·되돌리기). 정리하면 손글씨가 글자로 옮겨져 노트 아래에 붙고 필기 면은 비워집니다.
- **일정**: 놓친 할 일 / 오늘 / 내일 / 이번 7일 / 그 뒤 / 날짜 없는 할 일 순서. 위쪽 7일 달력을 누르면 그날만 봅니다.
- **캘린더로 보내기**: 일정 옆 달력 아이콘 → 구글 캘린더에 바로 추가 (삼성 캘린더가 구글 계정과 동기화돼 있으면 그대로 보임). 노트 목록 아래 "일정 전체 캘린더 파일(.ics)"로 한꺼번에 내보낼 수도 있습니다.
- 정리 후 내용을 고치고 다시 정리하면, 그 노트의 **안 끝난 일정만** 새로 바뀌고 완료한 것은 그대로 남습니다.

## 태블릿에 설치하기 (처음 한 번)

앱 파일은 https 주소에 올려야 태블릿에서 앱으로 설치됩니다. 무료로 가장 쉬운 방법:

1. PC에서 https://github.com 가입 → 새 저장소(Repository) 만들기 (예: `kkeojeok-note`)
2. **Add file → Upload files** 로 이 폴더의 파일 전부(README 제외해도 됨) 업로드
3. 저장소 **Settings → Pages** → Branch를 `main` / `(root)` 로 저장
4. 1~2분 뒤 나오는 주소(`https://아이디.github.io/kkeojeok-note/`)를 태블릿 **삼성 인터넷** 또는 **Chrome**에서 열기
5. 메뉴 → **홈 화면에 추가** (Chrome은 "앱 설치") → 홈 화면의 끄적노트 아이콘으로 실행

> 저장소를 공개로 만들면 앱 코드가 보이지만, 노트 내용과 API 키는 태블릿 안에만 있으므로 올라가지 않습니다.

## Claude API 키 넣기

1. PC에서 https://console.anthropic.com 가입 → 결제 수단 등록 → **API Keys**에서 키 만들기 (claude.ai 구독과는 별도 결제)
2. 앱 오른쪽 위 톱니바퀴 → API 키 붙여넣기 → **연결 테스트**
3. 모델 기본값은 Claude Opus 5.5. 더 빠르고 싸게 쓰려면 Sonnet 5.5나 Haiku 5.5를 고르세요.

비용 감각 (메모 길이에 따라 달라짐): 한 번 정리에 Opus 5.5는 대략 수십 원, Haiku 5.5는 1원 안팎입니다. 콘솔에서 월 사용 한도를 걸어 두는 것을 권합니다.

## 꼭 알아둘 점

- 노트는 태블릿 브라우저 저장소에 있습니다. 앱을 지우거나 브라우저 데이터를 삭제하면 사라지니 **설정 → 백업 파일 받기**를 가끔 해 두세요. 다른 기기로 옮길 때도 이 백업 파일을 **백업 불러오기**로 넣으면 됩니다.
- '정리'를 누르면 그 노트 내용이 Anthropic API로 전송됩니다. 환자 개인정보 등 민감한 내용은 정리 대상 노트에 적지 마세요.
- API 키는 태블릿에 저장되므로, 태블릿을 다른 사람과 같이 쓰면 키를 지우고 쓰세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면과 디자인 |
| `app.js` | 노트·일정 동작, 정리 신호 |
| `ink.js` | S Pen 필기 |
| `claude.js` | Claude API 호출 (정리 요청 문장도 여기) |
| `store.js` | 기기 저장, 날짜 계산 |
| `sw.js` | 오프라인 동작. 파일을 고쳐 다시 올릴 때 `VERSION` 숫자를 올리면 태블릿이 새 버전을 받습니다 |
| `manifest.webmanifest`, `icon-*` | 홈 화면 앱 설정과 아이콘 |
