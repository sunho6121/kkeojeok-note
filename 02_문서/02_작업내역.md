- 작성일: 2026-11-11
- 현재 버전: **kk-v20** (2026-11-11 배포)
- 주소: https://sunho6121.github.io/kkeojeok-note/

## 1. 개요

- 갤럭시탭 S9(S Pen)에서 쓰는 노트 앱(PWA)임
- 1~2개 노트에 계속 이어 쓰고, 신호를 주면 Claude가 일정·할 일·전달사항·중요 메모로 정리함
- 기본 원칙
  - claude.ai와 별개인 독립 앱임
  - 노트 쓰기는 로그인·인터넷 없이 가능함(기기 안 저장소 IndexedDB)
  - Claude는 '정리' 단계에만 씀(사용자 본인 API 키)
  - 기본 모델 Sonnet 5.5, 꼼꼼함(effort) 높음
  - 크레딧이 드는 음성→글자 변환(STT)은 넣지 않음
- 화면 원칙: 단순한 목록형, 개조식(~함·~임·명사형) 문체

## 2. 기본 사용 흐름

1. 쓰기 탭의 노트에 생각나는 대로 적음(타자 또는 필기)
2. 아침에 날짜만 한 줄 적음(예: `11/12`) → 전날까지 못 끝낸 일이 아래에 들어오고, 우선순위 창이 뜸
3. 마지막 줄에 `//`(또는 `@정리`, `정리!!`)를 쓰거나 **정리하기**를 누름 → Claude가 정리함
4. 업무·일정·전달·메모 탭에서 상태를 바꾸고 확인함
5. 회의는 녹음 → 녹취 글 공유 → 회의록 자동 생성(HWPX·DOCX·PDF)

## 3. 기능별 내용

### 3-1. 쓰기·정리

- 노트 칩으로 노트를 바꿈. 이번 달 노트만 보임
- 입력 방식: 타자 / 필기(S Pen). 필기는 정리할 때 글자로 옮겨져 노트에 붙음
- 정리 신호: 마지막 줄에 `//`, `@정리`, `정리!!` 또는 **정리하기** 버튼
- 인터넷이 없거나 API 키가 없으면 '정리 대기'로 두고, 연결되면 자동 정리함
- 정리 규칙(Claude)
  - 종류: 약속(event) · 할 일(task) · 전달사항(notice) · 중요 메모(memo)
  - 상태: 예정 · 진행중 · 보류 · 완결 · 취소. 기한이 지난 미완료는 '미완결'로 표시함
  - 같은 일은 기존 항목에 합치고(e1… 번호), 사용자가 직접 바꾼 상태·지운 항목은 건드리지 않음
  - 급함·꼭·중요·!!·★ → 우선순위 높음
  - 전달·메모는 제목 25자 이내 명사형, 설명 1~3줄 개조식
- 붙여넣기 버튼: 다른 앱에서 복사한 글·이미지를 노트에 넣음(이미지는 정리할 때 글자로 옮김)
- 받아쓰기: 브라우저 음성 인식(무료)으로 말을 글자로 적음

### 3-2. 날마다 이어 쓰기 · 우선순위 (kk-v19)

- 노트에 **날짜만 한 줄** 적으면, 그 아래에 전날까지 못 끝낸 일을 불러옴
  - 알아보는 형식: `11/12`, `11.12(목)`, `11월 12일`, `2026.11.12.`, `■ 11/12 ■`
  - 줄을 바꾸면 곧바로, 줄을 안 바꾸면 2~3초 멈춘 뒤 불러옴
  - 어제~사흘 뒤 날짜만 대상임. '11/12 회의'처럼 다른 글이 붙은 줄은 제외함
- 불러오는 대상
  - 기한이 지났는데 안 끝낸 할 일·전달사항
  - 기한 없이 전에 적어 둔 할 일
  - 보류는 뺌. 같은 날짜는 노트가 둘이어도 한 번만 불러옴
- 노트에 들어가는 모양(우선순위 → 기한 오래된 순)

  ```
  11/12(목)
  [이어서 할 일 · 11/11까지 못 끝낸 5건]
  - [높음] 동강홀 대관 신청 · 11/6까지·5일 지남
  - [보통] 운영위 자료 초안 작성 · 11/11까지, 진행 중
  - [낮음] 교육 만족도 설문 정리 · 기한 없음
  ```

- 우선순위 창
  - 우선순위를 아직 안 정한 일이 있으면 자동으로 뜸
  - 일마다 높음 · 보통 · 낮음 선택, 이미 끝낸 일은 '끝냄'
  - 저장하면 노트 목록에 `[높음]` 표시가 붙고 다시 정렬됨. 안 고른 일은 '보통'
  - '나중에'를 누르면 노트 위 안내 줄의 '우선순위 정하기'로 다시 열 수 있음
- 직접 정한 우선순위는 Claude 정리·업무보드가 바꾸지 않음
- 할 일 창(항목을 눌렀을 때)과 업무 탭에도 우선순위 표시·변경 기능 있음
- 필기 모드에서는 날짜를 알아볼 수 없음 → 노트 위 안내 줄의 **'지금 불러오기'** 사용
- 불러오기·정렬은 Claude를 쓰지 않아 크레딧이 들지 않음

### 3-3. 업무 탭

- 할 일: 기한 지남 / 이번 주 / 다음 / 기한 없음 / 보류. 같은 묶음 안에서는 우선순위 높은 것부터
- 한 일: 이 달에 끝낸 업무 + 회의록
- 월간 업무 요약(Claude): 한 줄 요약, 분야별 내용, 끝낸 일, 넘어가는 일, 기억할 것
- ‹ › 로 달 이동, 지난달은 '다음 달로 넘긴 일'을 보여 줌
- 업무보드 올리기 버튼, '↻ 보드 HH:MM 맞춤' 링크

### 3-4. 월별 노트

- 노트는 달마다 새로 시작함
- 새 달 첫 실행 때 지난달 노트를 닫고, 안 끝난 일을 새 달 노트로 넘김
- 지난달 업무 요약을 자동으로 만듦
- 노트 탭은 달별로 묶어 보여 줌

### 3-5. 일정 탭

- 보기 선택: 목록 / 주간(월~일 7칸) / 월간(월요일 시작 달력, 칸당 3개, +N)
- 월간 달력에서 날짜를 누르면 아래에 그날 목록이 나옴
- 종류(전체·약속·할 일)·상태(남은 일 등) 거르기

### 3-6. 전달·메모 탭

- 전달사항과 중요 메모를 한 줄 목록으로 보여 줌
- 비어 있으면 '노트에서 뽑아 정리하기'
- '간결하게 다듬기': 전달·메모를 개조식으로 다시 씀(Claude)

### 3-7. 녹음 · 회의록

- 녹음 버튼 → **"녹음을 시작할까요?"** 확인 창 → 시작 (kk-v18)
  - 안드로이드: 기기의 음성 녹음 앱을 열어 녹음하고 파일을 돌려받음(기본값)
  - 그 밖의 기기 또는 설정 변경 시: 끄적노트 안에서 녹음(m4a 우선)
  - 녹음 중 표시는 위쪽 알림 줄 없이, 녹음 버튼의 작은 빨간 점 + 시간만
  - 갤럭시탭 Chrome의 '데스크톱 버전'도 태블릿으로 알아봄
- 녹음이 끝나면 저장 확인 창. 녹음 중 쓴 메모도 함께 저장
- 녹음 탭: 듣기, 공유(다른 앱으로 보내기), 회의록 만들기
- 녹취 글 자동 연결
  - 삼성 음성 녹음 앱 등에서 녹취 글을 '공유 → 끄적노트'로 보내면 최근 녹음과 자동으로 묶음
  - 녹음이 없으면 '녹취 글' 항목을 새로 만듦
- 회의록 만들기(Claude)
  - 양식: 「회의록(원외 & 원내 협의체)」 2쪽 기준, 결재란·주관 칸 없음
  - 칸: 회의명 / 일시·장소 / 참석자 / 핵심요약 / 내용 / 결정사항 / 향후조치 / 첨부자료
  - 내려받기: 한글(HWPX) · Word(DOCX) · PDF(인쇄 화면에서 'PDF로 저장')
  - 향후조치 → 할 일, 결정사항 → 중요 메모로 자동 등록(설정에서 끌 수 있음)
  - 녹취 글이 들어오면 회의록 자동 생성(설정에서 끌 수 있음)

### 3-8. 구글 캘린더

- 사용자 본인 OAuth 클라이언트(프로젝트 "sunho note")로 연결
- 지난달 1일부터 120일 뒤까지 일정을 불러옴
- 끄적노트 · 구글 · 병원 그룹웨어 일정 중 같은 일정은 하나로 묶어 보여 줌
- 그룹웨어 일정은 구글 캘린더로 동기화된 경우에만 보임
- 끄적노트 일정을 구글 캘린더에 추가, ICS 내보내기

### 3-9. 업무보드 연결

- 대상: 공공보건의료사업팀 업무보드 https://uuh-board.uuh-phc.workers.dev/
- 연결: 보드 위쪽 「끄적노트 연결」에서 받은 개인 연결 키를 끄적노트 설정에 넣음
- 끄적노트 → 보드
  - 업무 탭 '업무보드에 올리기'에서 할 일을 골라 올림(담당·사업·분류 추측)
  - 올린 업무의 상태·기한·제목이 바뀌면 보드에도 맞춤
- 보드 → 끄적노트 (kk-v16)
  - 보드에서 바뀐 상태·기한을 받아 반영(보드 쪽 우선)
  - 담당에 내 이름이 있는 미완료 업무를 가져옴('보드' 표시)
  - 보드에서 지운 업무는 끄적노트에서도 지움
  - 받는 때: 앱 시작, 업무 탭 열 때, 5분마다, ↻ 누를 때
- 상태 대응: 예정↔예정, 진행 중↔진행중, 대기↔보류, 완료↔완결, 취소↔취소, 기한 지난 미완료 → 지연
- 우선순위는 아직 보드에 보내지 않음

### 3-10. 그 밖의 기능

- 삼성 노트 가져오기: PDF·글·이미지를 '공유 → 끄적노트' 또는 파일 선택으로 가져와 정리
- 메모 검색: 모든 노트 내용에서 찾기, 결과를 누르면 해당 위치로 이동
- 백업 내보내기·가져오기(녹음 파일은 용량 때문에 백업에서 뺌)
- 오프라인에서도 열림(서비스 워커 캐시)

## 6. 보안 · 개인정보 원칙

- Claude API 키와 업무보드 연결 키는 태블릿 앱 설정에만 둠. 채팅·다른 대화에 붙여넣지 않음
- 노트를 정리하면 내용이 Anthropic으로 전송됨 → 환자 개인정보는 적지 않음
- 회의록 정리 때도 개인정보를 가리도록 지시함
- 업무보드는 팀 공유 자료임. 쓰기 범위는 사용자 확인 후 진행함
- 업무보드 요청서(`_요청서/`)는 공개 저장소에 올리지 않음
- 커밋 작성자는 GitHub noreply 주소를 씀(병원 이메일 비공개)
- 시험할 때는 가짜 응답을 써서 실제 Claude 요청을 보내지 않음

## 7. 기술적 한계

- Claude API는 오디오를 받지 않음 → 녹음 글자 변환은 삼성 음성 녹음 앱(Galaxy AI)으로 하고 글을 공유받음
- 삼성 음성 녹음 앱은 가져오기·공유 받기 기능이 없음 → 끄적노트 녹음을 그 앱에 넣을 수 없음
- 끄적노트 안에서 한 녹음은 앱 안에만 저장되고, 앱을 닫으면 녹음이 멈춤
- 웹앱은 .hwp(바이너리)를 만들 수 없음 → .hwpx로 제공
- PDF는 인쇄 화면의 'PDF로 저장'으로 만듦
- 웹앱은 기기 캘린더를 직접 읽을 수 없음 → 그룹웨어는 구글 캘린더 동기화를 거쳐야 보임
- 필기(그림)로 쓴 날짜는 알아볼 수 없음
- 회의 STT를 외부 유료 서비스로 붙이는 것은 병원 정보 문제로 보류함
